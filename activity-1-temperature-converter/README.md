# Activity 1: Temperature Converter

File: `temperature_converter.py`

## Predict

What will each of the three `print` statements output? Write down all three
before you run anything.

## Run

Execute the file. Were your predictions right?

## Investigate

- What does the formula `(celsius * 9/5) + 32` actually do?
- What happens if you pass a negative number?
- Try `celsius_to_fahrenheit(-40)`. Explain the result to your partner.
- The function creates a variable called `fahrenheit` and then returns it. Could
  you return the calculation directly, without that variable? Would anything be
  lost by doing so?
